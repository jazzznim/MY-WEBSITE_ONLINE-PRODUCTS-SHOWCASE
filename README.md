# GLOW Beauty — Online Product Showcase

## Project description
GLOW Beauty is an original, fictional cosmetics brand concept created for an HTML & CSS web development activity. All product names, descriptions, and sample prices are invented for this project and are not claims about real products.

## Technologies
- HTML5
- CSS3
- No JavaScript

## Folder structure
```text
glow-beauty-showcase/
├── index.html
├── about.html
├── gallery.html
├── css/
│   └── style.css
├── images/
│   └── README.txt
└── README.md
```

## How to view the website
1. Download or extract the project folder.
2. Open `index.html` in a web browser.
3. Use the navigation links to visit Home, About, and Product Gallery.

## Publish with GitHub Pages
1. Create a new public GitHub repository.
2. Upload all files and folders while keeping the folder structure.
3. Open the repository's **Settings**.
4. Select **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)` folder, then save.
7. Wait for GitHub Pages to publish the site. Open the URL shown in the Pages section.

## Originality note
GLOW Beauty and the six displayed product concepts were made up for this student project. They are not copied from an existing cosmetics company or product catalog.
